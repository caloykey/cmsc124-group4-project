# LOLCODE Interpreter

CMSC 124 — University of the Philippines Los Baños

A Python application with a Tkinter GUI that performs lexical, syntax, and semantic analysis of LOLCODE programs.

## Requirements

Python 3 with Tkinter. Tkinter is normally included with the Windows Python installer. If missing, enable Tcl/Tk and IDLE in the installer.

## How to Run

1. Extract the ZIP file.
2. Open a terminal in the `source code (src)` folder containing `main.py`.
3. Run:

```bash
python main.py
```

On Windows, you can also use `py main.py`.

## How to Use

1. Click **Open File** to load a `.lol` file, or type code in the editor.
2. Click **Run**.
3. Enter input when requested.
4. View tokens and variable values in the **Tokens** and **Symbol Table** tabs. Output and errors appear in the **Console**.
